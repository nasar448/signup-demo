# Sign Up Page

A clean, modern sign-up/sign-in landing page with a purple brand theme and password visibility toggle.

## Project structure

- `index.html` – page structure
- `styles.css` – styling and responsive layout
- `script.js` – password toggle and form behavior

## Run locally

From the project folder, start a local static server:

```bash
python -m http.server 8001
```

Then open:

```text
http://localhost:8001
```

## Notes

This project is built as a static HTML/CSS/JS app, so it runs without additional dependencies.
